composer drupal-patch-check A composer plugin created to make it easy for humans to upgrade their patched Drupal websites. If you ever wanted to know if you still needed that patch after an update, or if your custom patch would still apply to the new version of the module, or if your 15 levels patch tower still applies after the update, this is the tool for you. Install the composer plugin and get started using the remote API.
