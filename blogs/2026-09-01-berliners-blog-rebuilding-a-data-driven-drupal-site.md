Rebuilding a data-driven Drupal site: Migrating page element configuration from Panels to Layout Builder In the previous post in this series, I described how we rebuilt our ctools page elements as block plugins. That gave us the new implementations, but not the pages that had already been assembled in Drupal 7. Recreating them manually would have taken a long time and risked losing existing configuration along the way.
