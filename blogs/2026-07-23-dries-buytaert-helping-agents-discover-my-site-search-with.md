Yesterday I blogged about the API catalog that announces my site's search API to agents. In response, someone pointed me to the ARD specification , a draft announced last month by a working group that includes Google, Microsoft, GitHub, Hugging Face, Cisco, Nvidia, and Salesforce. What ARD adds to yesterday's API catalog is discovery .
