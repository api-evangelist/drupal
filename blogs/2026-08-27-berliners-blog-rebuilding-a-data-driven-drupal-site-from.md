Rebuilding a data-driven Drupal site: From ctools plugins to Layout Builder blocks In the previous post , I described why we chose Layout Builder and how Layout Builder IPE restored the frontend editing workflow we had used with Panels IPE. With the editing workflow in place, we still had to rebuild the elements that editors placed on their pages. The Drupal 7 site used custom ctools content type plugins for maps, charts, figures, lists and tables.
